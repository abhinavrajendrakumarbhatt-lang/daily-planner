Daily Planner

A time-boxing tool for PMs and ICs who juggle multiple initiatives. Plan your day, set time boundaries, and block focus time on your calendar — all in one page.

Open Planner

How it works

1

Set your time budget

Enter your total work hours and meeting hours. The planner calculates your available deep work time and shows a progress bar as you allocate tasks.

2

Add tasks and pick today's slice

Add tasks to Today's Focus or Backlog. Each task can be tagged with an initiative. Use the Today / Backlog toggle to choose where new tasks land.

3

Time-box with durations

Set a duration for each today task (15m to 4h). This is your boundary — "I'll spend 2h on this, no more." The planner stacks them sequentially and shows each task's time slot.

4

Drag to prioritize

Grab the ⋮⋮ handle to reorder tasks. Drag between Today and Backlog. The order in Today's Focus is your schedule — reorder = reschedule.

5

Block focus time on calendar

Click "Block all on calendar" to step through each task and create Google Calendar events. Tasks stack sequentially starting from the next half hour.

One-click Google Calendar events with sequential time stacking.

⚙

Initiative Management

Create, tag, and manage your own initiatives. Click the gear icon.

Duration Picker

15m, 30m, 45m, 1h, up to 4h. Time slots update live as you change durations.

Surface Slack messages and emails needing your attention. Integrated with Claude Code.

Your data is private. All tasks, initiatives, and settings are stored in your browser's localStorage. Nobody else can see your data — even if you share this link with your whole team, everyone gets their own independent planner.

Tips

✓

First thing in the morning

Set your meeting hours, pull yesterday's unfinished tasks from Backlog into Today, time-box them, and hit "Block all on calendar."

✓

Customize your initiatives

Click the ⚙ gear icon next to the initiative dropdown. Add your real projects, delete the defaults.

✓

Daily auto-reset

When you open the planner the next day, unfinished today tasks move back to Backlog automatically. Fresh start every morning.

Slack Integration with Claude Code

Optional but powerful. Connect the planner to Claude Code to surface Slack messages needing your reply — right in the sidebar, every morning. Takes 2 minutes to set up.
1

Clone the repo

Open your terminal and run:

git clone https://github.com/abhinavrajendrakumarbhatt-lang/daily-planner.git

This downloads a CLAUDE.md file that teaches Claude Code what "refresh my planner" means.

2

Open Claude Code in the cloned folder

cd daily-planner
claude

Claude Code auto-loads the CLAUDE.md instructions when opened inside this folder.

3

Say "refresh my planner"

Claude searches your Slack DMs for messages you haven't replied to. It uses your own Slack identity via Fabric MCP (already configured org-wide at Booking) — it only sees messages sent to you.

4

Click the link Claude gives you

Claude generates a special link to the planner with your Slack data encoded in it. Click it once — the planner saves the data to your browser and the link becomes the normal planner URL. Your tasks and everything else stay untouched.

What you need & what you don't

Required

Claude Code installed
Git (for cloning the repo)
Fabric MCP connected (check with claude mcp list)

Not needed

No GitHub account
No API keys or tokens
No extra setup or config
No sign-up or login

Without Claude Code: The planner works perfectly on its own — you just won't get the Slack "Needs Reply" sidebar populated automatically. Everything else (tasks, time-boxing, drag-drop, calendar blocking) works without any setup.
